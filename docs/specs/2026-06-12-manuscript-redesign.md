# Eldoria Wiki — Illuminated Manuscript Redesign

Approved design from brainstorm with Trace, 2026-06-12.

## Theme
- Direction A: illuminated manuscript. Parchment CSS noise texture (light) / dark stone texture (dark).
- Content in double-line gold frames. Cinzel titles, Cormorant Garamond headers, EB Garamond body on reading pages.
- Gold glyph dividers (❦ ⸙ ⚜). NO emoji. Nav/cards use gold line-art SVG icons.

## Layout
- Top nav banner (royal blue, gold double rule): title, tabs Characters · Story · Locations · Organizations · Powers · Appendices, search, dark toggle.
- Explorer sidebar removed. Graph view removed. Breadcrumb ribbon kept. TOC floats right.
- Backlinks → "Referenced in" pill ribbon at article foot.
- Reading time shown ONLY on session notes + side stories.

## Homepage
Hero title → 6 nav cards (gold icons) → "The Current Party" (Campaign 2 PC portraits, auto) →
"Latest Chronicles" (newest C1 session + newest C2 session + 3 newest side stories, auto) → flourish.

## Landing pages (generated by sync.mjs as root-level pages to avoid folder-index slug ambiguity)
- Story: shelves — sessions by campaign, side-story cards, Events as in-world timeline (undated last).
- Locations: gazetteer tree grouped by country; reserved map slot.
- Organizations: heraldic card grid grouped by type; sigil slots.
- Powers / Appendices: styled scroll lists.
- Characters: existing All Characters page restyled.

## Reading pages
Session notes + side stories: serif body, gold drop cap on first paragraph, narrower column, ornamental scene dividers.

## Implementation notes
- Top nav injected post-build (scripts/postbuild.mjs) — identical markup on every page so SPA diffing keeps it stable.
- Search + dark toggle restyled/positioned into the nav strip via CSS.
- Workflow + preview must run postbuild after quartz build.
